# INT182 - YouTube Spam Detector

เครื่องมือ AI วิเคราะห์สำหรับ YouTuber ช่วยตรวจจับและคัดกรองคอมเมนต์สแปมโดยอัตโนมัติ

## ปัญหาที่แก้

คอมเมนต์สแปมจำนวนมากทำให้ข้อเสนอแนะและการสนทนาที่มีประโยชน์ของผู้ชมถูกกลบ
ส่งผลให้ครีเอเตอร์พลาดข้อมูลเชิงลึกและโอกาสสร้างปฏิสัมพันธ์กับชุมชน
เครื่องมือนี้ช่วยตรวจสอบสแปมอัตโนมัติ ลดเวลาคัดกรองด้วยมือหลายชั่วโมง
